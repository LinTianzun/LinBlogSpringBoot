## 一、项目概述

LinBlog 是一套前后端分离的个人博客系统，面向两类使用者：

- **访客**：通过门户匿名浏览文章、摄影图库、随笔与留言墙，可注册登录后评论、点赞、举报、发私信；
- **站长**：通过后台管理内容、用户、权限矩阵、举报处理、私信、本地文件与系统日志。

> **口径说明（2026-10-30 补充）**：本文档的「现状盘点」与「M1–M3 里程碑」两节写的是**旧版 Express 实现**（`serve/` + `lin_blog/`，11 张表，337 项后端测试 + 63 项前端测试），该项目已整体废弃。
> 当前现行工程是 **Vue 3 + Spring Boot 3.5 重实现版本**，其真实状态以 `Documentation/开发进度.md` 为准（后端 17 个端点已注册、22 张表已建、5 项阻塞级问题待解），里程碑以 `Documentation/Vue3-SpringBoot重实现开发文档.md` §10 的里程碑 0–7 为准。
> 本文档中「已交付能力」「质量基线」「技术债」等表述均属**旧版存档**，保留用于追溯设计输入来源；唯一已按重实现口径修正的是权限矩阵行。

系统已完成主要功能开发并通过 337 项后端测试 + 63 项前端测试。本立案覆盖**从当前基线到稳定上线、再到首轮运营与迭代**的计划，不重复罗列已完成历史，重点回答三个问题：还差什么、按什么顺序做、做到什么程度算完成。

## 二、现状盘点（截至 2026-10-29）

### 2.1 已交付能力

| 领域 | 能力 |
| --- | --- |
| 内容 | 文章/图库共用 `article` 表（`classify='article'|'image'`）、随笔独立表；草稿-发布-驳回状态流；分类（subset）与标签字典；富文本编辑（wangEditor） |
| 门户 | 四页门户（首页/文章/图库/随笔）+ 留言墙；详情弹窗深链接（`?open=<id>`、`?article=` 等）；canonical/OG/JSON-LD；`sitemap.xml`、`robots.txt`、`feed.xml` |
| 互动 | 两级评论（文章/随笔/图库通用表）、点赞、举报（6 类原因白名单 + 处理工作台）、真实浏览量（30 分钟去重）与最热排序 |
| 账号 | 注册/登录/JWT（7 天）、`token_version` 改密即失效、密码重置（SHA-256 令牌、30 分钟单次）、登录限流 |
| 权限 | 4 角色 × 33 键权限矩阵（重实现口径：8 组 33 键，存 `role_permissions` 表；旧版 Express 实现为 5 角色 × 37 项），超管唯一（`admin@linlog.com`），`permission.edit` / `user.assignAdmin` 受保护 |
| 私信 | 站内私信会话 + 未读实时提醒 |
| 文件 | 上传短期票据（5 分钟、按次消费）、图片 MEDIUMBLOB 入库 + 按需 WebP 缩略图（ETag/304）、软删 + 备份区（上限 2GiB、80% 告警）+ 可选跨盘镜像/S3 异地副本 |
| 安全 | helmet 系安全头、CORS 精确白名单（启动强校验）、写接口全局限流 + 敏感接口分路由限流、DOMPurify 清洗、无权限统一 404 防探测 |
| 运维 | 启动配置校验（不合规拒启）、访问日志 90 天滚动清理、优雅停机、迁移脚本 `npm run db:migrate`、演示数据种子 |

### 2.2 质量与工程基线

## 三、项目目标

**总目标**：把功能已齐备的 LinBlog 从「本地可跑」推进到「公网稳定运行、可持续迭代」，且全过程不牺牲现有 400 项测试与安全基线。

| 阶段 | 目标（可验收） |
| --- | --- |
| M1 质量收尾 | 近三天功能浏览器复测全部通过或缺陷闭环；editor chunk < 600KB 或阈值告警消除；测试/构建基线固化记录 |
| M2 部署上线 | 真实域名 HTTPS 可访问；SMTP 真实投递成功；搜索引擎可抓取 sitemap/feed；真实环境全流程回归通过 |
| M3 运营迭代 | 备份与保留策略正常运行；图片存储外移与 CI 两项技术债有结论（实施或明确缓办） |

## 四、范围界定

**本期范围内**：浏览器端回归测试、构建体积优化、生产环境部署（含域名/HTTPS/反代/SMTP/备份）、上线验收、首轮运营例行。

**本期范围外（明确不做）**：多租户/SaaS 化、第三方登录、国际化、移动端 App/小程序、门户大改版。新想法一律先进候选池（见 6.3），不直接插入本期。

## 六、资源与环境需求

| 项 | 要求 |
| --- | --- |
| 运行环境 | Node.js 22+（前端测试依赖 `--experimental-strip-types`）；MySQL 8.x 建议（utf8mb4） |
| 服务器 | 1 台入门云主机即可（sharp 缩略图与 MySQL 同机部署），2C4G 起步 |
| 域名与证书 | 1 个域名 + HTTPS 证书（反代终止即可）；境内服务器需完成备案 |
| SMTP | 任一邮件服务商 SMTP 账号（`LINBLOG_SMTP_*` 四项配置） |
| 对象存储（可选） | S3 兼容服务，仅用于文件异地副本，非必需 |
| 人力 | 单人开发 + 测试 + 部署；文档已齐备，可交接 |

## 七、关键风险与应对
